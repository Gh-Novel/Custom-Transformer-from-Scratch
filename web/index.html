How to Use Mini-GPT Live

This is a 3.17M-parameter decoder-only transformer built from scratch in PyTorch and trained on Tiny Shakespeare. It generates one character at a time. Watch the visualizations to see what the model is "thinking" before each character is sampled.

1 · Set your prompt

The model only knows Shakespeare text, so prompts that match its training distribution work best:

  • ROMEO:  JULIET:  HAMLET:  FALSTAFF: — character speakers
  • To be, or not to be,  All the world's a — famous line continuations
  • Enter ROMEO and JULIET  SCENE I. — stage directions

Tip: press Enter in the prompt box to generate.

2 · Tune the sliders

Tokens How many characters to generate. 200 is a good default; 500+ for full scenes.
Temperature Lower = safer, higher = more creative.
0.3 = deterministic, often repetitive. 0.8 = balanced default. 1.2+ = chaotic, may break grammar.
Top-k Restricts sampling to the k most likely characters. 0 = disabled (sample from full distribution). Try 10–40 to filter out unlikely garbage.
Speed Delay between tokens in milliseconds. Set to 80–150ms to actually watch the model think. 0 = generate as fast as the GPU allows.

3 · Read the visualizations

Attention Heatmap (top-left)

Each row represents a generated token. Each column represents a position in the context window. Cell brightness = how strongly that new token attended to that earlier position when it was being predicted.

What to look for:

  • Diagonal pattern — model is mostly looking at recent characters (local context)
  • Bright vertical stripes — model is anchored to specific earlier tokens (e.g. line breaks, character names)
  • Scattered/broad rows — model is uncertain or doing complex reasoning

Next-Token Probabilities (top-right)

The 10 most likely characters the model considered before sampling. The bar in green is the one that was actually chosen.

What to look for:

  • One huge bar near 100% — model is very confident (e.g. predicting T after JULIE)
  • Several balanced bars — model is at a decision point (e.g. start of a new word)
  • Flat distribution — model is uncertain; output quality may dip

Generated Text (bottom)

Streamed character-by-character. Your prompt is shown in purple; each new character flashes briefly as it arrives.

4 · Recommended first run

  1. Prompt: JULIET:
  2. Tokens: 200
  3. Temperature: 0.8
  4. Top-k: 0 (off)
  5. Speed: 100ms
  6. Click Generate and watch the heatmap grow.

Then try the same prompt at temperature=0.3 and 1.2 to see how the probability distribution shape changes — sharper at low temp, flatter at high temp.

What this is not

This is a 3M-param char-level model trained for 30 minutes on a single book's worth of text. It will invent words that sound Shakespearean but aren't real. That's expected — it learned the style, not a vocabulary. For comparison, GPT-2 small is 117M params trained on 40GB of text.
